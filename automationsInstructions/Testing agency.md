# Testing agency

Create bounded, non-CI tests in `testingAgencyTests` that each cover one SnaKt topic. Maintain a markdown diary recording the tested area, tests used, last execution time, run limits, results, and any bugs. When a bug is found, record it and create an issue labeled `bugFound`.

Runs are automated every two hours. Follow `AUTOMATIONS.md`, keep all repository changes on branches derived from `implementing-air-automations`, and sign commits with the Air Automations run signature.
