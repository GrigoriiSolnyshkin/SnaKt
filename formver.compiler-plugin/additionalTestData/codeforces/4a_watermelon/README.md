# Codeforces 4A — Watermelon

Source: <https://codeforces.com/problemset/problem/4/A>

Determine whether a positive integer weight is the sum of two positive even
integers. The Kotlin fixture includes the implementation and expresses the
exact expected result as a postcondition.

This candidate is suitable for FormVer because it uses only `Int`, `Boolean`,
comparison, remainder, and conjunction. It requires no unsupported contest I/O,
collections, library algorithms, or unbounded arithmetic.
